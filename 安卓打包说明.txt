============================================================
  fuckZHS 安卓版（APK）打包说明
============================================================

这个文件夹里是【安卓版】的完整源码和打包脚本。
要得到可以装到手机上的 .apk 文件，需要你自己在一台电脑上跑一次
打包命令（打包必须联网，第一次会比较慢）。

------------------------------------------------------------
 一、打包前你需要准备什么
------------------------------------------------------------
  • Windows 10 / 11（64 位）或 macOS / Linux
  • Docker Desktop（免费，官网 docker.com 下载）
      Windows 上装完 Docker Desktop 后要打开它，等左下角变成绿色
      "Engine running" 才算就绪。
  • 网络畅通，能访问 Docker Hub
  • 磁盘剩余空间 ≥ 15 GB

  ⚠ 打包需要下载 Android SDK / NDK（好几个 GB），
    第一次大概要 30 ~ 60 分钟。之后改代码再打包就快了（有缓存）。

------------------------------------------------------------
 二、怎么打包（Windows 最简单）
------------------------------------------------------------
  1. 打开 Docker Desktop，确认它已经完全启动。
  2. 双击本文件夹里的  docker-build.bat
  3. 会出现一个黑窗口在刷屏，那是正常的编译输出。
     中途不要关窗口。跑完会显示 BUILD SUCCESSFUL（或者类似字样）。
  4. 打包好的 APK 在：  bin\  文件夹里，名字类似
         fuckzhs-1.0.0-arm64-v8a_armeabi-v7a-debug.apk
     这个文件就是可以装到手机上的安装包。

  （如果你在 macOS / Linux，或者用 WSL2：
    在终端里执行  bash docker-build.sh   效果一样。）

------------------------------------------------------------
 三、怎么装到手机上
------------------------------------------------------------
  1. 把 bin\ 里那个 .apk 文件传到手机（微信/QQ/数据线都行）。
  2. 在手机上点开它。
  3. 系统会提示"不允许安装未知来源应用" —— 按提示去设置里
     允许"安装未知应用"（只针对你用的那个文件管理器或浏览器）即可。
  4. 装好之后桌面会出现一个叫 fuckZHS 的图标。

------------------------------------------------------------
 四、手机上怎么用
------------------------------------------------------------
  界面就是本文件夹里那张「手机版界面预览.png」的样子：

  1. 点【扫码登录】→ 用另一个手机（或让同学帮忙）打开
     "知到"App 扫屏幕上的二维码。
  2. 点【刷新】拉取课程列表，勾选要刷的课（都不勾 = 刷全部）。
  3. 【播放速度】一栏可手动输入任意数字，留空 = 用网站默认。
  4. 点【开始刷课】。想停就点【停止】。
  5. 下方日志区会实时打印所有操作和运行状态。

------------------------------------------------------------
 五、必须知道的注意事项（很重要）
------------------------------------------------------------
  ★ 刷课期间请让 App 留在前台、屏幕别灭。
    安卓系统（尤其是小米/华为/OPPO/vivo）会为了省电冻结后台应用，
    一被冻结，刷课就停了。程序已经申请了"屏幕常亮"权限，
    但各厂商策略不同，所以最好就让它一直亮着、别切走。

  ★ 被平台要验证码了怎么办？
    程序会弹窗提醒你。按提示到【电脑】上登录智慧树
    www.zhihuishu.com，打开正在刷的那一节课，手动播放一会儿，
    把弹出的验证码过掉，然后回到手机再点一次【开始刷课】，
    就会接着刷（已经刷上的进度不会丢）。

  ★ 手机和电脑可以共用同一份登录状态吗？
    不可以直接复制 cookies.json，因为两台设备的登录态是独立的。
    手机上第一次用需要自己扫码登录一次。

------------------------------------------------------------
 六、改了代码想重新打包
------------------------------------------------------------
  直接再跑一次 docker-build.bat 就行。
  缓存已经存在 Docker 卷里，第二次会快很多。

------------------------------------------------------------
 七、这一版改了什么（相对原始项目）
------------------------------------------------------------
  • 播放速度改为可手动输入任意数值，去掉了"速度偏高"的警告弹窗
  • 被验证码中断时弹窗提醒，并给出"去电脑端过验证码"的恢复步骤
  • 界面上所有操作、每个按钮点击、每次网络请求、任务开始/结束
    都会打印到日志区，出问题一眼能看出卡在哪一步
  • 布局改为自适应手机屏幕宽度，不再写死像素
