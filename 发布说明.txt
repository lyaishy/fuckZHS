============================================================
  fuckZHS 使用说明（给完全不懂电脑的人看）
============================================================

【第一步：怎么打开】
1. 把 fuckZHS.exe 从压缩包里“解压/提取”出来，不要直接在压缩包
   预览窗口里双击。建议放到 桌面 或 D:\ 这种自己的位置。
   ⚠ 不要放进 C:\Program Files 这类需要管理员权限的文件夹。

2. 双击 fuckZHS.exe。第一次打开会慢几秒钟，是正常现象（程序在自解压）。

3. 如果 Windows 弹出蓝色窗口写“Windows 已保护你的电脑”：
   点【更多信息】→ 再点【仍要运行】。
   原因：这个程序没有花钱购买数字签名，不是病毒。

【第二步：怎么用】
1. 点【扫码登录】，用手机“知到/智慧树”App 扫描窗口里的二维码。
2. 登录成功后，中间会列出你的课程，勾选想刷的课。
3. “播放速度”一栏：可以自己填任意数字。亲测填 400 没问题，超级快。
   留空 = 用网站默认速度。
4. 点【开始】，等它跑完。想中途停止点【停止】。
5. 界面上你做的每一步、程序跑的每一步都会打印到下方日志区，
   看不懂也没关系，出问题时把日志发我即可。

【第三步：看进度 / 出问题怎么办】
界面下方的日志区会实时显示在做什么。
程序也会在 exe 同一个文件夹里生成：
    logs\          运行日志（出问题时，把整个 logs 文件夹发我）
    cookies.json   登录状态（存了以后下次不用重新扫码）
    gui_settings.json  你填过的选项
    crash.log      崩溃记录（只有出错时才会出现）
以上文件都可以随便删，删掉会自动重建。

============================================================
  常见问题
============================================================

Q: 双击了一点反应都没有 / 窗口一闪就没了？
A: 说明程序启动就出错了。看 exe 旁边有没有 crash.log，
   有的话把它发给我，我就能定位。

Q: 提示“缺少依赖”？
A: 基本不会。这个 exe 已经把 Python 和所有依赖打包进去了，
   换任何一台 Windows 电脑都能直接跑。

Q: 一直提示验证码 / 进度卡住不动？
A: 说明被平台的风控拦了一下，不是出错，也不影响你的账号。
   程序会自己弹窗提醒你，按下面做就行：
   ① 到【电脑】上打开浏览器，登录智慧树 www.zhihuishu.com；
   ② 找到正在刷的那门课，打开正在卡住的那一节，手动播放一会儿；
   ③ 把页面上弹出的验证码过掉（滑块 / 图形 / 短信都算）；
   ④ 看到进度条正常往前走了，回到本程序，再点一次【开始刷课】，
      就会从卡住的地方接着刷（前面刷上的不会丢）。
   速度填多少都行（填 400 也没问题），和验证码没有必然关系。

Q: 杀毒软件报毒？
A: 这是 PyInstaller 打包程序的通病（没有数字签名），属于误报。
   选择“允许/信任”即可。

============================================================
  发给别人时注意

- 不要把自己的 cookies.json 一起发出去（那是你的登录状态）。
