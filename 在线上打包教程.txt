========================================================
 在 GitHub 上「在线」打包安卓 APK —— 保姆级教程
========================================================

为什么用这个办法
--------------------------------------------------------
你的电脑上没装 Docker，所以本地打不了 APK。
GitHub 提供免费的云端服务器（叫 GitHub Actions），
把代码传上去，它替你编译，打好的 APK 直接从网页下载。
你电脑上**什么都不用装**。

第一次大约 40~70 分钟（其中 30 分钟左右是等它下载 Android SDK/NDK，
约 2~3 GB）。以后再打包因为有缓存，只要 10~20 分钟。


========================================================
第一步 · 把代码放到你自己的 GitHub 账号下
========================================================

先选一种做法。推荐【做法 A】。

── 做法 A：Fork（复制一份到你自己名下，最快）──
1. 浏览器打开  https://github.com/VermiIIi0n/fuckZHS
2. 右上角点【Fork】，再点【Create fork】
   现在你名下就有一份了：https://github.com/你的用户名/fuckZHS
3. 继续看第二步

── 做法 B：自己新建一个空仓库 ──
1. 浏览器打开  https://github.com/new
2. Repository name 随便起个名，比如  fuckZHS-android
3. 选【Public】（公开仓库的 Actions 额度无限、完全免费，强烈建议）
   ⚠ 不要勾 "Add a README file"
4. 点【Create repository】
   新建出来的仓库名就叫 fuckZHS-android
5. 继续看第二步


========================================================
第二步 · 把本机代码推上去
========================================================

双击本目录里的  push-to-github.bat
按提示填「你的 GitHub 用户名」和「仓库名」，回车即可。

第一次会弹出浏览器让你登录 GitHub，点【授权】就行。
（这个脚本只是执行 git 推送，不会碰你的密码。）

推成功的标志：最后看到一行
    [成功] 已推送。
如果失败，按屏幕提示把报错发我。


========================================================
第三步 · 让它开始打包
========================================================

1. 浏览器打开你的仓库页面
2. 点顶部的【Actions】标签
   如果第一次进来有黄色提示条，点
   【I understand my workflows, go ahead and enable them】
3. 左边列表里点  「在线打包安卓 APK」
4. 右边点【Run workflow】按钮
     - 架构选  arm64-v8a（2017 年之后的手机基本都能装）
     - 再点绿色的【Run workflow】
5. 页面会冒出一条任务，前面是黄色转圈的图标，点进去能看实时日志
6. 等它跑完。跑完会变成绿色对勾 ✓


========================================================
第四步 · 下载 APK 并安装
========================================================

1. 任务变成绿色 ✓ 之后，点进这次任务
2. 页面**拉到最下面**，有个【Artifacts】区域
3. 点  fuckZHS-APK-arm64-v8a  下载（下载下来是个 .zip）
4. 解压，里面就是 .apk 文件
5. 把 .apk 传到手机（微信传、数据线拷、网盘都行），点击安装
   手机可能提示「未知来源应用」，允许一下就好


========================================================
常见问题
========================================================

Q: 任务变成红叉 ✗ 了怎么办？
A: 点进去，看哪一步是红的。把红色那段日志截图发我，我来判断。

Q: 一定要建公开仓库吗？
A: 私有仓库也能用，但免费账号每月只有 2000 分钟 Actions 额度，
   一次打包就要 40~70 分钟，额度很不经用。公开仓库则完全不限量、不花钱。
   本项目本身也是从公开仓库 fork 来的，公开没有额外风险。

Q: 会不会把我的账号密码传上去？
A: 不会。下面这些文件已被 .gitignore 排除，推不上去：
     cookies.json        登录会话
     config.json         可能填过账号/密码/pushplus token
     gui_settings.json   本机设置
   而且工作流里还有一道「安全闸门」：一旦在仓库里发现这些文件，
   会让构建**直接失败**，绝不产出带凭据的 APK。

Q: 手机上的 App 会一直刷吗？
A: ⚠ 一个重要提醒：安卓系统的省电策略可能会在长时间后台运行时
   把 App 冻结。刷课时尽量让屏幕保持亮着、别切走太久。
   App 内已经申请了 WAKE_LOCK 防止息屏，但各品牌手机策略不同。

Q: 能不能改成每次推送代码就自动打包？
A: 能。已经配好了：改动  buildozer.spec  或那个工作流文件并推送时，
   会自动触发一次打包。平时手动点 Run workflow 也行。
